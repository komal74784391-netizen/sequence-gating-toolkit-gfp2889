# Sequence Gating Toolkit

A general-purpose toolkit for sequence processing:

- tokenizers and vocabulary utilities
- attention masks and padding helpers
- generic gating and activation utilities

This toolkit is not an implementation of any specific paper or technical note. The gating
utilities were inspired by recent work on gated latent routing, but no routing layer from that
line of work is implemented here.
